# Assignment 4 - Forms and Validation

## About the Project

This project was created for Assignment 4. It contains five tasks about HTML forms, form validation, CSS styling, Bootstrap, and JavaScript.

The goal of this assignment is to learn how to create forms and check user input.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5

## Tasks

### Task 0 - Simple Contact Form

Created a simple contact form with name, email, message, and submit button.

### Task 1 - HTML5 Validation

Added HTML5 validation attributes such as `required`, `type`, `minlength`, and `maxlength`.

### Task 2 - Bootstrap Form

Used Bootstrap to style the form, add placeholders, helper text, and organize the layout.

### Task 3 - Validation Feedback

Added Bootstrap validation styles to show valid and invalid fields.

### Task 4 - Registration Form

Created a registration form with first name, last name, email, password, password confirmation, gender, hobbies, and country selection.

JavaScript checks if the passwords match and prevents submitting the form when validation fails.

## How to Run the Project

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a browser.
4. Choose any task from the main page.
5. Test the forms by entering different values.

## Conclusion

In this assignment, I learned how to create HTML forms, use Bootstrap for styling, and validate user input with HTML and JavaScript.
